# CS405-Lab-1-First-Square-in-WebGPU
A rotating, mouse-following square rendered with WebGPU. Built for CS405 Lab 1 as an extension of the classic "first triangle" starter, uses two triangles, aspect-ratio correction, and a uniform buffer to drive animation and mouse tracking from WGSL.
